# La tribu : journal de famille (app Home Assistant)

Collecte un groupe WhatsApp via WAHA, classe et rédige avec Claude (abonnement, sans clé d'API) et publie un site
privé protégé par mot de passe. Aucune donnée personnelle dans ce dépôt : jeton, clé WAHA, mot de passe, messages et
photos restent dans les options de l'app et dans le dossier de données de Home Assistant (`/share/familia-journal`).

Ajout dans Home Assistant : Paramètres, Apps, Boutique, menu ⋮, Dépôts, puis l'adresse de ce dépôt.
